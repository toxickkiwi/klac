# Вакансии для «Клацай, працуй!»

Каждый день в 8:00 бот присылает в Telegram 10 новых вакансий: название, кратко что нужно делать и ссылку.

Как это работает:
- Вакансии ищутся на 6 сайтах по всей Беларуси: **rabota.by, praca.by, minsk.business, belmeta.com, careerist.ru, bebee.com**. Список сайтов задаётся в `sources` в config.yaml. Сначала Минск и удалёнка.
- Можно включить фильтр по опыту работы: без опыта, 1–3 года, 3–6 лет, от 6 лет.
- Первыми идут вакансии по маркетингу, потом SMM и event, потом project, product и IT.
- Уже присланные вакансии больше не повторяются, а от одной компании в день приходит не больше одной вакансии.
- Всё работает бесплатно на GitHub, компьютер включать не нужно.

Под сообщением есть кнопка **➕ Ещё 5 вакансий**. Она присылает ещё 5 вакансий, которых не было утром (настройка описана ниже).

Пример сообщения:

> 🗓 **Вакансии на 06.10**
>
> 1. **Технический маркетолог / ООО ПанСтройГарант, Минск**
> Опыт: 1–3 года
> Что делать: Формирование маркетингового плана на период; анализ метрик; работа с подрядчиками.
> 🔗 https://rabota.by/vacancy/...

## Запуск (один раз, ~10 минут)

### Шаг 1. Создать бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте боту имя и username (он должен заканчиваться на `bot`, например `klacprac_vacancies_bot`).
3. BotFather пришлёт сообщение со строкой вида `1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`. Это **токен** — пароль от бота. Скопируйте его. **Никому его не показывайте.**
4. Найдите своего бота в поиске Telegram и нажмите **Start**. Без этого бот не сможет вам писать.

### Шаг 2. Узнать свой chat ID
1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите **Start**.
2. Он пришлёт ваш **Id**, это число вроде `123456789`. Скопируйте его.

### Шаг 3. Добавить токен и ID в GitHub
«Секрет» — это просто место на GitHub, где хранятся пароли. Нужно сохранить туда два значения из шагов 1 и 2:

| Name (название, вписать точно так) | Secret (значение) |
|---|---|
| `TELEGRAM_TOKEN` | токен бота из шага 1, например `1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw` |
| `TELEGRAM_CHAT_ID` | ваш Id из шага 2, например `123456789` |

1. Откройте репозиторий на github.com → вкладка **Settings** (вверху) → слева **Secrets and variables** → **Actions**.
2. Нажмите зелёную кнопку **New repository secret**.
3. В поле **Name** впишите `TELEGRAM_TOKEN`, в поле **Secret** вставьте токен → **Add secret**.
4. Снова **New repository secret**: Name — `TELEGRAM_CHAT_ID`, Secret — ваш Id → **Add secret**.

Значения секретов не видит никто, даже вы сами после сохранения. В коде их нет, хотя репозиторий публичный.

### Шаг 4. Проверить
1. Вкладка **Actions** → слева **Вакансии дня** → справа **Run workflow** → зелёная кнопка **Run workflow**.
2. Через 2–3 минуты в Telegram придёт сообщение с вакансиями.
3. Если запуск стал красным ❌, откройте его, нажмите на шаг с ошибкой и пришлите текст ошибки разработчику.

Дальше бот присылает вакансии сам каждый день около 8:00, включая выходные.

## Кнопка «Ещё 5 вакансий» (один раз, ~15 минут)

Под утренней подборкой есть кнопка **➕ Ещё 5 вакансий**. Такую же кнопку можно закрепить внизу чата или вместо неё написать боту `/more`. Через 2–3 минуты бот пришлёт 5 вакансий, которых ещё не было, ни утром, ни раньше.

Чтобы кнопка заработала, нужен маленький бесплатный бот-помощник на Cloudflare. Он «слышит» нажатие и запускает поиск на GitHub.

### Шаг 1. Токен GitHub, чтобы помощник мог запускать поиск
1. На github.com нажмите на свою аватарку справа вверху → **Settings** → в самом низу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. **Token name:** `klac-bot`. **Expiration:** максимальный срок. Когда срок закончится, токен нужно будет создать заново.
3. **Repository access:** **Only select repositories** → выберите `klac`.
4. **Permissions** → **Repository permissions** → **Actions** → **Read and write**.
5. Нажмите **Generate token** и скопируйте токен (начинается с `github_pat_`). Больше GitHub его не покажет.

### Шаг 2. Создать помощника на Cloudflare
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up). Это бесплатно, карта не нужна.
2. Слева **Compute (Workers)** → **Workers & Pages** → **Create** → **Start with Hello World!** → придумайте имя, например `klac-bot` → **Deploy**.
3. Нажмите **Edit code**, удалите весь код слева и вставьте содержимое файла [`worker.js`](worker.js) из этого репозитория. Откройте файл → кнопка **Copy raw file** справа вверху. Затем нажмите **Deploy** справа вверху.
4. Вернитесь к помощнику → **Settings** → **Variables and Secrets** → **Add**. Добавьте три значения, у каждого выберите **Type: Secret**:

| Variable name | Value |
|---|---|
| `TELEGRAM_TOKEN` | токен бота (тот же, что на GitHub) |
| `TELEGRAM_CHAT_ID` | ваш Id (тот же, что на GitHub) |
| `GITHUB_TOKEN` | токен из шага 1 (`github_pat_…`) |

5. Нажмите **Deploy**, чтобы сохранить.

### Шаг 3. Подключить к Telegram
1. Скопируйте адрес помощника. Он вверху страницы и выглядит как `https://klac-bot.ваше-имя.workers.dev`.
2. Допишите в конце `/setup` и откройте в браузере: `https://klac-bot.ваше-имя.workers.dev/setup`.
3. Должно появиться «✅ Готово!».
4. Напишите боту `/start`. Внизу появится кнопка **➕ Ещё 5 вакансий**. Нажмите её и через 2–3 минуты получите вакансии.

Если вместо вакансий пришло «⚠️ Не получилось запустить поиск», проверьте `GITHUB_TOKEN` (шаг 1, особенно права **Actions: Read and write**).

Без помощника дополнительную подборку можно получить и на GitHub: **Actions** → **Вакансии дня** → **Run workflow**, в поле «Сколько вакансий» впишите `5`, в «mode» выберите `extra`.

## Как дать пользоваться ботом другим

Бот присылает вакансии всем, чьи Id перечислены в `TELEGRAM_CHAT_ID` через запятую. Всем остальным он отвечает «нет доступа».

**Вариант 1 — общая группа (удобно для команды).**
1. Создайте группу в Telegram и добавьте туда бота и нужных людей.
2. Напишите в группе `/id`. Бот ответит числом вида `-1001234567890`.
3. Добавьте это число через запятую к своему Id в двух местах:
   - **GitHub:** Settings → Secrets and variables → Actions → `TELEGRAM_CHAT_ID` → карандаш ✏️ (Update) → например `655277412, -1001234567890`;
   - **Cloudflare:** помощник `klac-bot` → Settings → Variables and Secrets → `TELEGRAM_CHAT_ID` → карандаш → то же значение → Deploy.
4. С завтрашнего утра подборка приходит и вам, и в группу. Кнопка «Ещё 5» работает в обоих чатах.

**Вариант 2 — отдельному человеку в личку.**
1. Человек открывает бота и пишет `/start`. Бот ответит: «Перешлите владельцу бота этот Id: …».
2. Добавьте этот Id через запятую в тех же двух местах, что и в варианте 1.

Дополнительная подборка («Ещё 5») приходит всем получателям сразу, чтобы вакансии ни у кого не повторялись.
Чтобы убрать человека, удалите его Id из обоих мест.

## Как менять настройки

Всё в файле [`config.yaml`](config.yaml). Откройте его на github.com, нажмите карандаш ✏️, поменяйте и нажмите **Commit changes**.

- **Сколько вакансий в день:** `per_day: 10`. Если список не помещается в одно сообщение Telegram, он придёт несколькими.
- **Опыт работы:** `experience: [без опыта, 1-3]` — варианты `без опыта`, `1-3`, `3-6`, `6+`. Пустые скобки `[]` значат любой опыт. Если опыт в вакансии не указан, она показывается, пока стоит `experience_unknown: true`. Чтобы такие вакансии не приходили, поставьте `false`.
- **Убрать неподходящие:** добавьте слова в `stop_words`, например `stop_words: [продаж, стажер]`. Вакансии с этими словами в названии будут пропускаться.
- **Добавить сферу или слово:** у каждой сферы есть `search` (что искать на сайтах) и `title` (какие слова должны быть в названии вакансии). Например, чтобы ловить «бренд-амбассадоров», добавьте `амбассадор` в оба списка нужной сферы.
- **Поменять важность:** число `priority`. Чем оно меньше, тем раньше берутся вакансии этой сферы.

**Разовый подбор с другим опытом.** Откройте **Actions** → **Вакансии дня** → **Run workflow**, в списке «Опыт работы» выберите нужный вариант и нажмите **Run workflow**. Бот сразу пришлёт вакансии с этим опытом, а ежедневная рассылка останется как в `config.yaml`.

Время отправки меняется в файле `.github/workflows/daily.yml`, в строке `cron: "50 4 * * *"`. Время там указано по UTC, это минус 3 часа от Минска: `50 4` — это 7:50 по Минску.

## Если что-то пошло не так

- **Сообщение не пришло.** Откройте **Actions** и посмотрите последний запуск. GitHub иногда запускает задачи с опозданием до получаса.
- **В сообщении «⚠️ … не удалось получить вакансии».** Сайт не открылся или поменял вёрстку. Вакансии с другого сайта всё равно придут, а парсер нужно будет поправить.
- **Нужно, чтобы вакансия пришла ещё раз.** Удалите её строки из `sent.json`.
