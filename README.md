# Вакансии для «Клацай, працуй!»

Каждый день в 8:00 бот присылает в Telegram 2 новые вакансии: название, кратко что нужно делать и ссылку.

Как это работает:
- Вакансии ищутся на **rabota.by** и **praca.by** по всей Беларуси, сначала Минск и удалёнка.
- Первыми идут вакансии по маркетингу, потом SMM и event, потом project, product и IT.
- Уже присланные вакансии больше не повторяются, а от одной компании в день приходит не больше одной вакансии.
- Всё работает бесплатно на GitHub, компьютер включать не нужно.

Пример сообщения:

> 🗓 **Вакансии на 06.10**
>
> 1. **Технический маркетолог / ООО ПанСтройГарант, Минск**
> Что делать: Формирование маркетингового плана на период; анализ метрик; работа с подрядчиками.
> 🔗 https://rabota.by/vacancy/...

## Запуск (один раз, ~10 минут)

### Шаг 1. Создать бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте боту имя и username (он должен заканчиваться на `bot`, например `klacprac_vacancies_bot`).
3. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAH...`. Скопируйте её. **Никому её не показывайте.**
4. Найдите своего бота в поиске Telegram и нажмите **Start**. Без этого бот не сможет вам писать.

### Шаг 2. Узнать свой chat ID
1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите **Start**.
2. Он пришлёт ваш **Id**, это число вроде `123456789`. Скопируйте его.

### Шаг 3. Добавить токен и ID в GitHub
1. Откройте репозиторий на github.com → **Settings** → слева **Secrets and variables** → **Actions**.
2. Нажмите **New repository secret**:
   - Name: `TELEGRAM_TOKEN`, Secret: токен из шага 1 → **Add secret**.
3. Ещё раз **New repository secret**:
   - Name: `TELEGRAM_CHAT_ID`, Secret: число из шага 2 → **Add secret**.

Секреты видите только вы. В коде их нет, даже при публичном репозитории.

### Шаг 4. Проверить
1. Вкладка **Actions** → слева **Вакансии дня** → справа **Run workflow** → зелёная кнопка **Run workflow**.
2. Через 2–3 минуты в Telegram придёт сообщение с вакансиями.
3. Если запуск стал красным ❌, откройте его, нажмите на шаг с ошибкой и пришлите текст ошибки разработчику.

Дальше бот присылает вакансии сам каждый день около 8:00, включая выходные.

## Как менять настройки

Всё в файле [`config.yaml`](config.yaml). Откройте его на github.com, нажмите карандаш ✏️, поменяйте и нажмите **Commit changes**.

- **Сколько вакансий в день:** `per_day: 2`.
- **Убрать неподходящие:** добавьте слова в `stop_words`, например `stop_words: [продаж, стажер]`. Вакансии с этими словами в названии будут пропускаться.
- **Добавить сферу или слово:** у каждой сферы есть `search` (что искать на сайтах) и `title` (какие слова должны быть в названии вакансии). Например, чтобы ловить «бренд-амбассадоров», добавьте `амбассадор` в оба списка нужной сферы.
- **Поменять важность:** число `priority`. Чем оно меньше, тем раньше берутся вакансии этой сферы.

Время отправки меняется в файле `.github/workflows/daily.yml`, в строке `cron: "50 4 * * *"`. Время там указано по UTC, это минус 3 часа от Минска: `50 4` — это 7:50 по Минску.

## Если что-то пошло не так

- **Сообщение не пришло.** Откройте **Actions** и посмотрите последний запуск. GitHub иногда запускает задачи с опозданием до получаса.
- **В сообщении «⚠️ … не удалось получить вакансии».** Сайт не открылся или поменял вёрстку. Вакансии с другого сайта всё равно придут, а парсер нужно будет поправить.
- **Нужно, чтобы вакансия пришла ещё раз.** Удалите её строки из `sent.json`.
